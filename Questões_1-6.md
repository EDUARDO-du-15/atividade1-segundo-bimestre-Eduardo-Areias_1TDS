# atividade1-segundo-bimestre-Eduardo-Areias_1TDS

1- O comando "programa" define o inicio do programa, a função "inicio" define onde começará a sua execução no terminal, incluindo as funções, os comandos e a entrada de dados já dentro do da função inicio, podemos observar o comando "escreva", como o próprio nome já diz, ela escreve no terminal (onde os comandos são representados) um texto de sua escolha, ele funciona da seguinte forma: "escreva("Olá mundo")", o comando "escreva" fará aparecer o texto "Olá mundo" (muito importante o uso das aspas no caso de um texto), além disto, este comando funciona somente em compania dos parênteses.
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
2- O código a seguir funciona de forma semelhante ao anterior, mantendo sua estrutura, porém com a incrementação de mais um comando escreva, até a linha 5, o comando será executado da mesma forma que o anterior, mas na linha 6, será escrito mais um texto no terminal, a frase "Como vai", porém, o texto aparecerá "um colado no outro", da seguinte forma: "Olá mundoComo vai", para a resolução do problema, é recomendado que se use um espaço no final de "Olá mundo" ou no inicio de "Como vai" ou o uso do comando "\n", usado para pular para linha de baixo do terminal.
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
3- Na imagem desta atividade, é demonstrada uma das possívei correções para evitar o problema citado no item 2, ele usa do \n para a organização dos textos que aparecerão no terminal, os textos aparecerão da seguinte maneira:  "Olá mundo,  esta correção do código organizou a aparição dos textos do terminal utilizando o comando \n.
                       Como vai"
