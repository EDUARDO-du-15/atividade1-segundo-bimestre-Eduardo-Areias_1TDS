# atividade1-segundo-bimestre-Eduardo-Areias_1TDS

1- O comando "programa" define o inicio do programa, a função "inicio" define onde começará a sua execução no terminal, incluindo as funções, os comandos e a entrada de dados, já dentro da função inicio, podemos observar o comando "escreva", que como o próprio nome já diz, ela escreve no terminal (onde os comandos são representados) um texto de sua escolha, neste código, ele funciona da seguinte forma: "escreva("Olá mundo")", o comando "escreva" fará aparecer o texto "Olá mundo" (muito importante o uso das aspas no caso de um texto).

2- O código a seguir funciona de forma semelhante ao anterior, mantendo sua estrutura, porém com a incrementação de mais um comando escreva, até a linha 5, o comando será executado da mesma forma que o anterior, mas na linha 6, será escrito mais um texto no terminal, a frase "Como vai", porém, o texto aparecerá "um colado no outro", da seguinte forma: "Olá mundoComo vai", para a resolução do problema, é recomendado que se use um espaço no final de "Olá mundo" ou no inicio de "Como vai" ou o uso do comando "\n", usado para pular para linha de baixo do terminal.

3- Na imagem desta atividade, é demonstrada uma das possívei correções para evitar o problema citado no item 2, ele usa do \n para a organização dos textos que aparecerão no terminal, os textos aparecerão da seguinte maneira:  "Olá mundo,//pula uma linha//Como vai", esta correção do código organizou a aparição dos textos do terminal utilizando o comando \n.

4- Dentro da função inicio, temos uma criação de variável, um comando de inserção/atribuição(leia) e um "escreva", a criação de variável cria uma variável do tipo cadeia, este tipo de variável espera a entrada de dados referentes à letras e símbolos, já o comando "leia" permite a inserção de informações pelo usuário em uma determinada variável. Em ordem, este algoritmo cria uma variável do tipo cadeia, espera a atribuição de informações pelo usuário e depois escreve estas informações no terminal (no caso deste algoritmo, parece que ele espera a atribuição de um nome, por mais que não especifique ao usuário).

5- Quando o código for executado, aparecerão 3 mensagens (devido aos 3 "escreva"), elas estarão separadas, uma em cada linha (por conta do \n), as mensagens são: "123"; "300"; "100+200", a primeira apareceu devido o uso do número 123 dentro do comando "escreva", o segundo efetuou a operação "100+200" descrita no outro comando, já o terceiro, não efetuouesta operação, pois ela estava descrita entre aspas, ou seja, o comando escreva apenas fará aparecer os números e as operações, sem realizá-las (quando o texto está entre aspas, ele é inteiramente escrito no terminal, já quando está sem, podemos utilizá-lo para escrever resultados de operações ou informações de uma variável)

6- O código cria uma variável do tipo inteiro, chamada "idade", atribui o valor 21 à ela e a utiliza no comando condicional "se", como o próprio nome já diz, se algo for verdadeiro, uma acão decrita dentro das chaves "{}" será realizada, no caso, caso a idade seja maior ou igual à 18 (o que é verdadeiro), ele escreve a frase "maior de idade".
